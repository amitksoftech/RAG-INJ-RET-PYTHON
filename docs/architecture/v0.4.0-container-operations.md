# Container operations — v0.4.0

## Change

The service now runs as two process roles from one non-root Docker image: API and Dramatiq worker. Docker Compose starts PostgreSQL, Redis, Qdrant, and MinIO locally.

```mermaid
flowchart TB
    Compose[Docker Compose] --> API[API container]
    Compose --> Worker[Worker container]
    API --> PG[(PostgreSQL volume)]
    API --> Redis[(Redis volume)]
    Worker --> Qdrant[(Qdrant volume)]
    Worker --> MinIO[(MinIO volume)]
    API --> Health[/healthz /readyz /metrics]
```

## Operational rules

- Run Alembic migrations before accepting ingestion traffic.
- Back up PostgreSQL and Qdrant persistent volumes; raw sources are retained in object storage.
- Logs are structured JSON and include request/job correlation IDs, never raw document text or credentials.

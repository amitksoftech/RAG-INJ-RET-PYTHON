# Architecture document history

Architecture documents are immutable, versioned design records. Every material design change adds a new file containing a Mermaid diagram, decision summary, and compatibility notes.

- Major versions: breaking API, storage, or deployment changes.
- Minor versions: new capabilities or components.
- Patch versions: documentation-only clarifications.
